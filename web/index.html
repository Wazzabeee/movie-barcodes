    Waiting for frames: keep this tab visible and the window uncovered, browsers stop decoding video in background tabs.

    Works best in Chrome or Edge (desktop). Keep the tab visible while it runs. Colors match the movie-barcodes Python package within a few levels per channel. The browser has to support the movie's codec: H.264 and HEVC in MP4 or MKV work in Chrome on macOS; Safari does not open MKV files.
